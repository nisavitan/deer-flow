# exp7-headless

Working directory used for the headless-CLI experiments (E7-a, E1-a/b/c, E3-a, E4-b).
The runs were invoked from here with `--plugin-dir ../exp1-plugin/deerflow-poc`; they produce
no artifacts on disk by design (`--no-session-persistence`). The full command transcript and
outputs are recorded in `../RESULTS-log.md` and summarized in
`docs/claude-code-port/experiment-results.md`.
